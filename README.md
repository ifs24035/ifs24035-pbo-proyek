## 📘 Deskripsi Singkat

Nuel’s Pawtopia adalah aplikasi web untuk mengelola penitipan hewan.
Dibangun menggunakan Java Spring Boot, sistem ini menyediakan:
- CRUD data hewan & pemilik
- Perhitungan biaya otomatis
- Dashboard statistik
- Upload foto hewan
- Sistem kode kandang otomatis
- Autentikasi aman (Spring Security + BCrypt)
- Aplikasi ini dikembangkan sebagai bagian dari mata kuliah Pemrograman Berorientasi Objek.
